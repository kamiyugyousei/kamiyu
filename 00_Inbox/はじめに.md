# はじめに

この Vault は GitHub リポジトリ `kamiyugyousei/kamiyu` と同期しています。

- 新規ノートはまず `00_Inbox` に作成されます。整理したら `10_Notes` へ移動してください。
- デイリーノート（コマンドパレット →「デイリーノートを開く」）は `20_Daily` に作成されます。
- テンプレートは `90_Templates`、画像などの添付は `99_Attachments` に入ります。

セットアップ手順はリポジトリ直下の [[README]] を参照してください。
